# spotiget

Link-to-audio converter: paste a track, album or playlist link and get an mp3 —
no registration.

**Website: [https://spotiget.com](https://spotiget.com)**

## Example

`convert_audio.py` converts audio files that are already on your disk between
formats via ffmpeg (nothing is downloaded):

```bash
python convert_audio.py input.wav output.mp3 320k
```

Requires `ffmpeg` on PATH.

The full product lives at [https://spotiget.com](https://spotiget.com).
